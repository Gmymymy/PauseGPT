# PauseGPT

**看视频时遇到不认识的人、不知道的地方、没见过的工具？**

暂停，按一下，直接问 AI。

---

> 当前版本（v1.0）模型识别准确率有限，对冷门人物/小众场景效果一般。AI 可能给出不准确答案，建议使用内置搜索验证功能核实。欢迎 Star 关注后续更新。

---

## 为什么做这个

你一定遇到过这种情况：

- 看综艺，有个演员脸熟但叫不出名字
- 看技术视频，博主用了某个工具但没说名字
- 看舞蹈，想知道跳的是什么风格
- 看旅行 vlog，某个取景地特别好看想去

现在的解法：**暂停 → 截图 → 打开搜索引擎 → 上传图片 → 等结果**，5 步操作，大多数人直接放弃。

PauseGPT 把这个流程压缩成：**暂停 → Alt+T → 直接问**。

---

## 功能

- **截帧识别**：自动截取视频当前帧，发送给 AI 分析
- **流式输出**：AI 逐字输出，有打字机光标效果，无需等待
- **自由提问**：不限问题类型，想问什么问什么
- **多轮追问**：AI 始终保持对画面的记忆，支持连续对话

```
你：这个人是谁？
AI：从外貌特征判断可能是 XXX，但不确定，建议搜索确认
你：她穿的是什么风格的衣服？
AI：图中人物身穿深色无袖连衣裙，风格偏向...
```

- **搜索验证**：每条 AI 回复底部自动生成「🔍 搜索」按钮，精准提取关键词跳转百度搜索，快速核实 AI 答案
- **新画面**：一键切换新帧，开启新对话
- **可拖动浮窗**：不遮挡视频，随意拖拽

## 安装

### 1. 获取 API Key

前往 [阿里云百炼控制台](https://bailian.console.aliyun.com) 注册，获取 DashScope API Key（`sk-xxx` 格式）

需开通模型：`qwen-vl-max-2025-08-13`（新用户有免费额度）

### 2. 加载插件

```bash
git clone https://github.com/Gmymymy/PauseGPT.git
```

1. Chrome 打开 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择项目文件夹

### 3. 填入 API Key

点击浏览器右上角 PauseGPT 图标 → 输入 API Key → 保存

### 4. 开始使用

打开 B 站视频 → 暂停在想问的画面 → 按 `Alt+T` → 提问

## 技术实现

```
视频帧截取（Canvas API）
    ↓
Base64 编码（最大宽度 1920px，JPEG 质量 0.92）
    ↓
阿里云 DashScope API（qwen-vl-max-2025-08-13）流式请求
    ↓
SSE 流式解析，逐 token 推送给 content script
    ↓
多轮对话管理（每轮携带图片 + 完整历史）
    ↓
浮窗流式渲染 + 搜索关键词自动提取
```

## 当前局限

- **人物识别准确率有限**：对冷门艺人、非公众人物识别效果一般，大众明星相对准确
- **模型幻觉**：AI 可能给出听起来自信但不准确的答案，重要信息请点「搜索验证」核实
- **歌曲识别能力弱**：仅凭歌词字幕识别歌曲名准确率较低，建议直接用歌词搜索
- **部分网站截帧失败**：跨域保护的视频内容无法截取
